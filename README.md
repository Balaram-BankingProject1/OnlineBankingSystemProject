# Online Banking & Dashboard

## 📌 Overview
The **Online Banking & Dashboard** <br>project is a backend-driven banking portal designed to provide secure, scalable, and efficient digital banking services. It bridges the gap between traditional banking processes and modern technological solutions by offering RESTful APIs for account management, fund transfers, and transaction history.

Developed as part of the MCA program (2023–2025) at **Gandhi Academy of Technology and Engineering, Berhampur (BPUT)**.

---

## 🎯 Objectives
- Provide a secure and extensible online banking platform.
- Automate banking activities such as:
  - User registration & authentication
  - Account creation & management
  - Fund transfers
  - Transaction history tracking
- Ensure robust **data security** with password encryption, role-based access control, and secure session management.
- Support modular design for future features (loans, credit cards, investments).

---

## 📖 Scope
### For Customers:
- Register and log in securely.
- Create and manage accounts (savings/current).
- Perform intra-bank fund transfers.
- View detailed transaction history.

### For Administrators:
- Approve/reject customer registrations.
- Monitor and manage all transactions.
- Access user activity dashboards.

---

## ⚙️ Tech Stack
- **Backend:** Java 11, Spring Boot, Hibernate ORM
- **Database:** MySQL
- **API Design:** RESTful APIs
- **Build Tool:** Maven
- **Security:** Bcrypt password hashing, SQL injection protection, authenticated sessions

---

## 🛠️ Features
- Real-time transaction processing
- Encrypted password storage
- Role-based access control (Customer/Admin)
- Modular architecture for scalability
- REST APIs ready for integration with web/mobile frontends

---

## 🚫 Limitations
- Backend-only (no GUI frontend included in this version).
- Single-currency support.
- No third-party payment gateway integration (e.g., UPI, PayPal).
- Limited to basic banking services (no loans, credit cards, insurance).

---

## 🔮 Future Scope
- Multi-currency support
- Loan & credit card modules
- Integration with external payment gateways
- Mobile/web frontend development
- Advanced analytics dashboards
